# ai/workflows/

Prozessdefinitionen für alle Entwicklungsarbeiten.

| Datei | Wann verwenden |
|-------|----------------|
| `feature-workflow.md` | Neue Features, Erweiterungen |
| `bugfix-workflow.md` | Fehler beheben |
| `review-workflow.md` | Code-Review nach Implementierung |

## Grundregel

Jeder Workflow hat explizite **STOP-Punkte**.
An einem STOP-Punkt wird die Arbeit unterbrochen, die Situation dokumentiert,
und der Nutzer entscheidet wie es weitergeht.

Kein Agent überbrückt einen STOP-Punkt durch Annahmen.
